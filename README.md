# The Loom Room by Neri

A marketing strategy portfolio connecting expertise, experience, creative execution, and applied insights.

## Site structure

- `index.html` — homepage
- `expertise.html` — marketing capabilities
- `experience.html` — professional experience
- `insights.html` — applied marketing insights
- `insights/` — individual Insight article pages
  - `insight-01.html`
  - `insight-02.html`
  - `insight-03.html`
- `contact.html` — contact page
- `style.css` — shared styles
- `main.js` — shared JavaScript

Lab & Lore remains a separate companion site for scholarly, educational, reflective, and long-form work.
